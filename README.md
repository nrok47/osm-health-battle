# อสม. ปราบข่าวลวง — เกมต่อสู้สไตล์ Pokémon

โปรเจคเกมสุขภาพตัวที่ 2 ต่อจาก [tambon-health-game](https://github.com/nrok47/tambon-health-game)

เกมต่อสู้ 1v1 แบบ Pokémon Red/Blue ที่เปลี่ยนความหมายของทุกอย่างให้เป็นงานสุขภาพพื้นที่

| ของเดิมในโปเกมอน | ในเกมนี้ |
|---|---|
| HP ของมอนสเตอร์ฝั่งตรงข้าม | **ความเชื่อผิด / ความดื้อ** ของชาวบ้าน — ตีให้หมด = เขายอมเข้าระบบติดตาม |
| HP ของเรา | **พลังใจ / ความน่าเชื่อถือ** ของ อสม. — หมดคือวันนี้คุยไม่จบ |
| ท่าโจมตี | **ประโยคที่เราเลือกพูด** 4 ตัวเลือก |
| ธาตุ (Fire/Water) | **วิชาสื่อสาร 3 สาย** × **สาเหตุที่เขาเชื่อ** |
| ไอเทม | โทรหาหมอ รพ.สต. · แผ่นพับ · กาแฟ |
| ยิม + บอส | 3 ยิมโรค เบาหวาน / ไต / ความดัน |
| Pokédex | **เล่มทะเบียนชาวบ้าน** — เจอแล้วจึงรู้ว่าเขาเชื่อเพราะอะไร |

## หัวใจของเกม — ทำไมมันไม่ใช่แบบทดสอบปรนัย

ตอบถูกตามหลักวิชาอย่างเดียว **ยังไม่พอ** เพราะความแรงของคำตอบขึ้นกับว่าเขาเชื่อเพราะอะไร

| เขาเชื่อเพราะ | 📊 ข้อมูล | 🫂 เรื่องเล่า | ❓ ชวนคิด |
|---|---|---|---|
| ไม่เคยมีใครอธิบาย | **×1.6** | ×1.0 | ×0.7 |
| คนที่เขานับถือบอกมา | ×0.7 | **×1.6** | ×1.0 |
| ไม่ได้ขาดข้อมูล แต่ไม่ยอมให้ใครสั่ง | ×0.6 | ×1.0 | **×1.6** |

แถวล่างคือของจริงที่เจอในพื้นที่ — **คนดื้อ ยิ่งยัดข้อมูล ยิ่งต้าน** (backfire effect)
เกมจึงลงโทษคนที่ใช้วิธีเดียวกับทุกคน และยังไม่เฉลยว่าใครเป็นแบบไหนจนกว่าจะลงไปคุยครั้งแรก

ตัวเลือกมี 4 ชนิด และ **ไม่บอกชนิดก่อนกด** :

- **ตรงจุด** — ถูกหลักวิชาและตรงกับสิ่งที่เขาติด → ลดความเชื่อผิดเต็มแรง + เขาเปิดใจ 2 รอบ
- **ทั่วไป** — ไม่ผิด แต่ไม่เปลี่ยนอะไร → ลดนิดเดียว และโดนสวนกลับ
- **เข้าตัวเอง** — ผิดหลักวิชา (เช่น "น้ำผึ้งไม่ขึ้นน้ำตาล") → **เสียพลังใจเรา** เพราะเขาจำไปใช้ต่อแล้วเราต้องตามแก้เอง
- **พลาดหนัก** — ขู่ ด่าคนที่เขานับถือ สั่ง → เขาตื่นตระหนก 2 รอบ พูดอะไรก็เข้าหัวได้น้อยลง

ทุกรอบจบด้วย **เกร็ดที่ใช้ได้จริง** — เนื้อหาการแพทย์อ้างหลักวิชาจริงทุกบรรทัด

### สามอย่างที่ทำให้เล่นซ้ำแล้วไม่เหมือนเดิม

1. **สุ่มลำดับคำถาม** — ชาวบ้านคนละ 5 ข้อ แต่มาไม่เรียงกัน เจอคนเดิมสองรอบไม่ได้บทเดิม
2. **สลับตำแหน่งตัวเลือก** — จำไม่ได้ว่า "กด a" เพราะข้อถูกย้ายที่ทุกครั้ง
3. **เพดานเวลาเยี่ยม 8 รอบ (บอส 10)** — เลือกวิชาผิดจะยืดเป็น 11-16 รอบแล้วคุยไม่ทัน
   นี่คือตัวที่ทำให้ "เลือกวิชา" มีราคา ไม่ใช่แค่ตอบถูกอย่างเดียวจบ

ทั้งสามอย่างผูกกับ seed — ใส่เลขเดิมได้ชุดเดิมเป๊ะ เปลี่ยนเลขได้ชุดใหม่
เกมจำ **สถิติดีที่สุดของแต่ละ seed** ไว้ให้กลับมาทำลายสถิติตัวเอง

### โหมดยาก

พลังใจเหลือ 70 · เวลาเยี่ยมเหลือ 5 รอบ (บอส 7) · และ **ไม่เฉลยว่าวิชาไหนเข้าทางใคร**
เล่นถูกเป๊ะถึงจะทัน — พลาดข้อเดียวต่อเคสคือตกจากเกรด S ไป D

## วิธีเล่น

```
Space / คลิกกล่องข้อความ  เดินบทถัดไป (กดซ้ำระหว่างพิมพ์ = ข้ามแอนิเมชัน)
1-4                       เมนูหลัก (ไฟท์ / ไอเทม / เปลี่ยนวิชา / ถอย)
a b c d                   เลือกคำตอบตอนอยู่ในเมนูไฟท์
Esc                       กลับเมนูหลัก
```

ยิมถัดไปเปิดเมื่อชนะครบทุกคนในยิมก่อนหน้า · ถอยตั้งหลักได้ แต่คะแนนปลายปีนับที่จำนวนคนเข้าระบบ

## อยากอ่านคำถาม-คำตอบทั้งหมด

เปิด **[QUESTIONS.md](QUESTIONS.md)** — คำถามทั้ง 45 ข้อ พร้อมเฉลยว่าตัวเลือกไหนเป็นชนิดไหน
และเกร็ดความรู้ของแต่ละข้อ อ่านรวดเดียวจบโดยไม่ต้องเปิดโค้ดและไม่ต้องเล่นเกม

ไฟล์นั้นสร้างจาก `js/data.js` อัตโนมัติ จึงไม่มีทางไม่ตรงกับในเกม
แก้เนื้อหาที่ `js/data.js` แล้วรัน `node tools/dump-questions.js` ใหม่

## ไฟล์

```
index.html
css/battle.css   ฉากต่อสู้ ป้าย HP กล่องข้อความ แอนิเมชันสั่น/เลขลอย
js/data.js   ←   เนื้อหาทั้งหมด: 3 ยิม · 9 ชาวบ้าน · 45 คำถาม · 180 ตัวเลือก · ตัวเลขสมดุล
js/pixel.js  ←   pixel art วาดเองจากตารางตัวอักษร 16×20 ไม่มีไฟล์ภาพเลย
js/engine.js     กลไกการสู้ ไม่มีโค้ดหน้าจอปน
js/ui.js         หน้าจอ ไม่มีสูตรปน
QUESTIONS.md ←   คลังคำถามทั้งหมดในรูปแบบอ่านง่าย (สร้างอัตโนมัติ ห้ามแก้มือ)
```

**แก้เนื้อหา/สมดุล = แก้ `js/data.js` ไฟล์เดียว** · **แก้หน้าตาตัวละคร = แก้ `js/pixel.js` ที่เดียว**

**อยากเพิ่มคำถามเกิน 5 ข้อ/คน:** ใส่เพิ่มใน `q[]` ได้เลย ไม่ต้องแก้โค้ดและไม่ต้องขยับ `hp`
ระบบสุ่มลำดับและมีเพดานรอบอยู่แล้ว ยิ่งคลังคำถามใหญ่ ยิ่งได้เจอชุดใหม่ทุกรอบที่กลับมาเล่น

ไม่ใช้ไลบรารีภายนอก ไม่มี build step — เปิด `index.html` ได้เลย
การสุ่มทั้งหมดผูกกับ seed (ใส่เลขเดิมได้ผลเดิม) จึงเล่นซ้ำเพื่อเทียบวิธีพูดได้

## ทำไมวาด pixel art เอง ไม่ใช้ Kenney

บทเรียนตรงจาก tambon-health-game : ชุด CC0 ที่มีอยู่ (Tiny Town/Tiny Dungeon)
**ไม่มีคนสูงวัยไทย ไม่มีชุด อสม. ไม่มีสัญลักษณ์สาธารณสุข** สุดท้ายต้องวาดกาชาดเองอยู่ดี
คราวนี้เลยวาดทั้งตัวเองตั้งแต่แรก — เป็นตารางตัวอักษรใน `pixel.js` เปลี่ยนสีผม/ผิว/เสื้อ/หมวกได้ต่อคน
ผลคือ **ไม่มี dependency ภาพเลย ทั้งเกมเป็นข้อความล้วน** และเพิ่มตัวละครใหม่ใช้เวลาไม่กี่นาที

## ที่มา

โครงการสู้ตั้งต้นมาจากการระดมไอเดียว่า "ถ้าทำเรื่องนี้ให้เป็นเกมแบบโปเกมอนจะหน้าตาเป็นยังไง"
— HP = ความดื้อ, ตัวเลือกคำตอบ = ท่าที่มี Type ต่างกัน, ยิม 3 โรค

สิ่งที่เพิ่มเข้ามาทีหลังและเป็นตัวที่ทำให้มันเป็นเกมจริง ๆ คือ **ชั้นวิชาสื่อสาร × สาเหตุที่เขาเชื่อ**
ซึ่งทำให้ "ตอบถูกตามหลักวิชาอย่างเดียวยังไม่ชนะ" — ต้องอ่านคนให้ออกก่อนว่าจะพูดยังไง
